# aqsually 0.1.0

- First release of aqsually, formerly aqsclient.
- Provides an R client for 79 EPA Air Quality System API operations.
- Reads API credentials from AQS_KEY and supports offline request construction.
- Includes generated help pages and offline checks for all 76 authenticated query wrappers.
- Adds automated source package builds and checks on Linux, Windows, and macOS.
