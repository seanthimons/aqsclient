# aqsclient

An R client generated by specmill from the EPA Air Quality System schema.
Includes all 79 schema operations, their configuration and help pages, the
unaltered downloaded schema, offline tests, and live audit results.

## Build and install

Install R, extract this folder, and run from the extracted `aqsclient` directory:

```sh
Rscript init.R
```

The script installs missing runtime dependencies from CRAN, builds a source
archive in `build/`, installs the client in `library/`, and runs offline request
tests. It does not contact AQS. Internet access is needed only for missing
dependencies; compiling dependencies from source may require your platform's
usual R build tools. Tested with R 4.5.0 on Linux.

The generated source is included, so specmill is not needed for this step.
The source archive can also be installed using `R CMD INSTALL`.

In a fresh R session from this directory:

```r
.libPaths(c('library', .libPaths()))
library(aqsclient)
```

## Use your own AQS account

Copy `.Renviron.example` to `.Renviron`, fill in your email and key, and load it:

```r
readRenviron('.Renviron')
key <- Sys.getenv('AQS_KEY')
set_api_token(key)
meta_data_is_available()
list_states(email = Sys.getenv('AQS_EMAIL'), key = key)
sample_data_by_state(
  email = Sys.getenv('AQS_EMAIL'), key = key,
  param = '88101', bdate = 20180303L, edate = 20180303L, state = '16'
)
```

No credentials are included in this bundle. `.Renviron` is excluded from Git and
R package builds. EPA declares the key as both a required query argument and a
security credential on many endpoints; use the same value in `set_api_token()`
and the wrapper argument. Dates are YYYYMMDD integers. State, county and site
codes are strings retaining leading zeroes.

## Known live API differences

The audit attempted all 78 read-only routes. Across baseline and follow-up
queries, 64 returned data, 11 returned valid empty results, and one returned a
healthy status. Four of those routes required the workaround below.

- `transactions_sample_by_state()`, `_by_county()`, `_by_site()`, and `_by_ma()`
  require `units = NULL`. The live API rejects the schema default `standard`.
- `transactions_sample_by_poc()` returns HTTP 422: no matching service exists.
- Use `meta_data_is_available()` for health checks. `service_available()` returns
  an untyped body containing HTTP headers rather than the declared JSON.
- `signup()` creates an account or resets the account key and sends email. It was
  deliberately excluded from the audit.

Example transaction request:

```r
transactions_sample_by_state(
  email = Sys.getenv('AQS_EMAIL'), key = key, param = '88101',
  bdate = 20180301L, edate = 20180301L, state = '16', units = NULL
)
```

These findings describe the audit's requests, not every possible input or future
API behavior. See [the endpoint-by-endpoint report](audit/README.md), its CSV
results, and [lessons for specmill](LEARNINGS.md). Recommended policy changes are
not applied here; generated defaults are retained to reproduce the findings.

## Schema and regeneration

`schema/aqs_api_specification.json` is the original EPA download.
`schema/openapi.json` is an identical working copy. [Source and checksum](schema/SOURCE.md).
The `apis/` YAML files give each method/path a distinct R name, resolving the
duplicate `qaAnnualPerformanceEvaluationsBySite` operationId.

Only regeneration requires specmill. This client was regenerated with specmill
0.1.60 at the source revision below:

```r
# Optional maintainer setup; not needed by init.R or package users.
install.packages('remotes')
remotes::install_github(
  'seanthimons/specmill@1c1553b9233d874876f0f13c98ef09b191dc00e9'
)
```

Restart R after installing specmill, then run from this directory:

```r
specmill::generate_client('.', config = 'specmill.yml', mode = 'plan')
# Review the plan before applying:
specmill::generate_client('.', config = 'specmill.yml', mode = 'apply')
specmill::generate_client('.', config = 'specmill.yml', mode = 'check')
```

Keep `.specmill/` with the project: it tracks generated-file ownership and helper
provenance. The pinned revision records the generator used for this rebuild.

## Rerun the live audit

This is optional and uses your own credentials. It requires the pinned specmill
and its dependencies in addition to the client runtime dependencies. Archive
existing CSVs/logs outside `audit/` for a fresh sweep, or retain `results.csv` to
resume an interrupted baseline. From this directory, run sequentially:

```sh
Rscript audit/run.R
Rscript audit/diagnose.R
Rscript audit/positive-controls.R
Rscript audit/transaction-workaround.R
```

The scripts pause 6.2 seconds between requests, disable retries, and use bounded
queries. Do not run them concurrently. See [EPA's service documentation and
request limits](https://aqs.epa.gov/aqsweb/documents/data_api.html).
